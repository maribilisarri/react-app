# MovieLand 🎥

A simple React app that uses the OMDb API to search and display movie details dynamically, with a user-friendly interface.

## Features
- Search for movies using the OMDb API.
- Automatically displays a list of movies with the title "Batman" on load.
- Dynamic rendering of movie results as cards.
- Fallback message when no movies are found.
